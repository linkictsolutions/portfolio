# Design drops

Drop raw project assets here. One folder per project.

Structure (copy `_template/` for each new project):

```
design-drops/
  <project-slug>/
    notes.md         # the write-up (brief, role, key screens, signature moment, outcome)
    screens-svg/     # hero screens as .svg  (best — recreated in code)
    screens-png/     # screens as .png @2x   (reference + gallery)
    video/           # optional .mp4 screen recordings
    figma.txt        # Figma view/prototype link + any color/font specs
```

Naming: lowercase, hyphenated (e.g. `medytic`, `my-ecommerce`).
Screen files: `01-dashboard.svg`, `02-family-overview.svg`, … (order matters).
